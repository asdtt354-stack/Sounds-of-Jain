# 자인의 소리

자인중학교 전교생 16명이 자인시장과 계정숲에서 듣고, 시로 쓰고, 노래로 만든 마을 이야기를 듣는 페이지입니다.
책 『자인의 소리』에 실린 QR 코드가 이 페이지의 각 곡으로 이어집니다.

## 파일
- `index.html` — 화면
- `songs-data.js` — 곡 목록(제목, 지은이, 노랫말). 노래를 바꾸거나 더할 때는 이 파일만 고칩니다.
- `audio/` — 노래 파일. 이름은 `번호-영문이름.mp3`

## 곡 번호
주소 끝의 `#번호`가 곡을 가리킵니다(예: `#12` 구름빵). 책에 인쇄된 QR에 들어가므로 번호는 바꾸지 않습니다.
- 00 주제가 / 01~16 마을의 소리(자인시장) / 21~ 숲의 소리(계정숲) / 17~18 함께 부르는 노래
